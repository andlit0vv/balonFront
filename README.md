# BALON Frontend

Локальная версия сайта BALON Drop 01 после доработки дизайна.
Статический сайт: HTML, CSS и JavaScript, без сборки и зависимостей.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/ — стартовый экран; `/#shop` — каталог.

## Состав

- `index.html` — стартовый экран, каталог, карточки товаров, корзина.
- `assets/` — общие стили, скрипты, шрифты и изображения.
- `delivery.html`, `contacts.html` — информация покупателям.
- `oferta.html`, `privacy.html`, `consent.html`, `marketing-consent.html` — документы.
- `docs/product-questions.md` — вопросы команде для заполнения характеристик.

## Что ещё требуется для запуска продаж

- Подключить создание и хранение заказов, оплату ЮKassa и подтверждение платежей.
- Подключить актуальные пункты выдачи и расчёт доставки СДЭК: сейчас используются демонстрационные данные.
- Подтвердить характеристики, наличие и фотографии товаров.
- Заполнить шаблонные сведения в документах, проверить контакты и описание используемых сервисов.

Окно после кнопки «Оплатить» демонстрационное: реальный платёж не создаётся.
Корзина сохраняется локально в браузере; данные получателя хранятся только в памяти страницы.

## Проверка интерфейса

В браузере проверены каталог, галерея товара, добавление в корзину,
изменение количества и пересчёт суммы, сохранение введённых данных при
изменении количества и пустая корзина. Просмотрены мобильная и широкая версии.
